# xmens

Code for Çevrim *et al.*, *Transgenic menstruating mice reveal the spatial logic of pre-menstrual uterine
differentiation* (earlier version on [bioRxiv](https://doi.org/10.1101/2025.10.08.681007)).

| | folder | |
|---|---|---|
| 1 | `preprocess/` | FASTQs to QC'd objects |
| 2 | `notebooks/Integration, Cleaning, and Annotation.ipynb` | annotation |
| 3 | `pseudotime/` | pseudotime |
| 4 | `mi/` | genes associated with pseudotime |
| 5 | `samap/` | human-mouse alignment (SAMap) |
| 6 | `notebooks/` | notebooks that make the final AnnData objects |
| 7 | `figures/pt_heatmaps/` | heatmaps along pseudotime |
| 8 | `figures/` | figures |
| 9 | `tables/` | QC table |

`orthology/` holds the ortholog table used in step 4; `environments/` lists the software.

Data will be available upon publication.
