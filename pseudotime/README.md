# pseudotime

Diffusion pseudotime of the fibroblast and decidual nuclei, run in JupyterLab with the `rsc_uv` kernel on a GPU.

| notebook | reads | object |
|---|---|---|
| `pseudotime_mouse_final_1110.ipynb` | `20261110_mouse_only_eFib_dec_final.h5ad` | `20261110_mouse_only_eFib_dec_final_nick_pdt.h5ad` |
| `pseudotime_human_final_1112.ipynb` | `20261107_Human_allcells_final.h5ad` | `20261112_Human_fibdec_final_nick_pdt.h5ad` |

`pseudotime_human_final_1107.ipynb` is the earlier human run, rooted in eFib2; `pseudotime_human_reroot_1112.ipynb`
moves its root to eFib1. Only the two notebooks above made objects used in the paper.
