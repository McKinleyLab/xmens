# pseudotime

Diffusion pseudotime of the fibroblast and decidual nuclei, run in JupyterLab with the `rsc_uv` kernel on a GPU.

- `pseudotime_mouse_final_1110.ipynb`: mouse pseudotime
- `pseudotime_human_final_1112.ipynb`: human pseudotime
- `pseudotime_human_final_1107.ipynb`: an earlier human run, rooted in eFib2
- `pseudotime_human_reroot_1112.ipynb`: moves the root of the 1107 run to eFib1

The human notebooks use the earlier subtype names: eFib1 is now myoFib, and eFib2 is now eFib_a.
